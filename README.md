# assistant-core

What the Assistant apps (Android, macOS, the web) draw the same on every platform: TeX math
(RaTeX, KaTeX's syntax, fonts and metrics) and Mermaid diagrams (mmdr), as vector shapes that
each platform paints with its own canvas. Text in them is set in the fonts the app registers
(`fonts/`, the ones its editor shows) and drawn as glyph outlines, so nothing depends on the
fonts a machine happens to have.

- `register_font(bytes)`: the app's text fonts (Pretendard), before drawing.
- `render_math(tex, display, font_size, color)` → `Drawing`
- `render_mermaid(source, dark)` → `Drawing`
- `markdown_spans(text)` → the note's structure (CommonMark, GFM, $…$ math) as spans, each with the
  Markdown syntax an editor hides while the cursor isn't in it; offsets are UTF-16 units.

A `Drawing` is a size, a baseline and shapes: paths (move, line, quadratic, cubic, close) filled
or stroked in one ARGB colour.

## Building

Rust from rustup (`/opt/homebrew/opt/rustup/bin`), with the targets each app needs.

    cargo test                                   # tests, with the fonts in fonts/
    cargo run --example preview -- out/          # drawings as SVG files, to look at
    cargo ndk -t arm64-v8a --platform 29 build --release --lib   # Android (cargo install cargo-ndk)
    cargo run --bin uniffi-bindgen generate --library <lib> --language kotlin|swift --out-dir <dir>

The Android and macOS builds run these themselves (see their repos).

## What's here

- `src/`: the core; bindings are generated by UniFFI.
- `fonts/`: Pretendard 1.3.9 (SIL OFL 1.1, `fonts/OFL-Pretendard.txt`), the text font everywhere.
- `vendor/`: mermaid-rs-renderer with one change (fonts supplied by the app); see `vendor/README.md`.
